# Plan: External debt (ULN) history + chart

**Status:** ready to execute · **Owner decision needed:** see §2 · **Target executor:** a cost-efficient
model following `.claude/skills/execute-plan/SKILL.md` (invoke `/execute-plan docs/plans/2026-08-external-debt-history.md`).

Read `CLAUDE.md` first. Everything in it applies (generated files, BigInt rule, domain-agnostic,
anonymity, sanity checks, design fidelity). This plan only adds to it.

## 1. Goal

Add a **quarterly history of Indonesia's external debt (Utang Luar Negeri, ULN)** to the site as a
new full-width section: a build-time SVG line chart, a "what changed" strip (QoQ / YoY / 5-year),
and a downloadable JSON. Data comes from Bank Indonesia's SULNI
(https://www.bi.go.id/en/statistik/ekonomi-keuangan/sulni/Default.aspx).

Why: today the site shows one ULN number (the "Utang luar negeri pemerintah" card) with no trend.
Readers and journalists ask "is it going up?"; a chart answers that without adding a backend.

Non-goals (do NOT do): a JS chart library, any npm dependency, monthly granularity, private-sector
deep dives, currency/maturity breakdowns, animated charts, a second page. Keep total page weight
under the handoff's 100 KB budget; the SVG must stay ≲ 8 KB.

SULNI facts the executor can rely on (verified 2026-08-22): editions are monthly, listed at
`/en/statistik/ekonomi-keuangan/sulni/Pages/SULNI-<BulanIndonesia>-<YYYY>.aspx`; each edition has
`Documents/SULNI-<Bulan>-<YYYY>.pdf` and `.zip` (xlsx tables). The **August 2026** edition
(published 2026-08-18) carries the **June 2026** position — i.e. ~2-month lag. Headline as already
recorded in `debt.json`: government ULN ≈ USD 216.3 bn at June 2026; total ULN ≈ USD 453.4 bn.
Use these two numbers as a cross-check when transcribing. SULNI "Government" ULN *includes* SBN held
by non-residents — say so in the note text (the card note already hints at it).

## 3. Data model

New file `data/external-debt.json` (human-edited, committed):

```json
{
  "unit": "USD million",
  "edition": "SULNI Agustus 2026",
  "edition_en": "SULNI August 2026",
  "source_url": "https://www.bi.go.id/en/statistik/ekonomi-keuangan/sulni/Pages/SULNI-Agustus-2026.aspx",
  "_note": "Quarter-end positions from SULNI Table 1 (external debt by group of borrower). Government includes SBN held by non-residents. Values in USD millions, plain numbers.",
  "series": [
    { "date": "2014-03-31", "total": 276400, "government": 123500, "central_bank": 7600, "private": 145300 },
    { "date": "2026-06-30", "total": 453400, "government": 216300, "central_bank": 0, "private": 0 }
  ]
}
```

(Values above are **placeholders** except the two June-2026 headline numbers; replace all from the source.)
Rules: dates strictly increasing and each must be a quarter-end (`-03-31`, `-06-30`, `-09-30`,
`-12-31`); `government + central_bank + private` must equal `total` within **0.5 %** (SULNI rounds);
every value `> 0`; consecutive `total` must not jump more than **±25 %** (typo guard, same spirit
as `checkRateSanity`). Minimum 8 points.

Generated (build output, never hand-edit; add to the CI `git add` list in `.github/workflows/build.yml`):
`public/external-debt.json` — a copy of the series plus `generated_at`, for readers who want the raw
numbers; referenced from the JSON-LD `Dataset.distribution` and the "Sumber data" list.

### T2 — Chart generator (`feat(uln): build-time SVG line chart`)
- [ ] Create `scripts/lib/chart.js` exporting `renderLineChart({ series, keys, width, height, lang })`
      returning an SVG string. Requirements:
      - `viewBox="0 0 W H"`, `width="100%"`, `preserveAspectRatio="xMidYMid meet"`; W=960, H=360.
      - Y axis starts at **0** (no truncated axes on a debt site); nice-rounded ticks (4–5 gridlines),
        labels in **USD bn** (`fmt` via `scripts/lib/format.js`, Indonesian decimal comma for `id`).
      - X labels: one per year at the Q4 point, IBM Plex Mono via CSS class (no inline fonts).
      - Two `<path>` lines with classes `chart-line--government` and `chart-line--total`; no fills;
        `stroke-width` 2 / 1.5; `vector-effect="non-scaling-stroke"`.
      - Last point of each series: a `<circle r="4">` plus a text label with the value.
      - A `<title>` on the root SVG and `role="img" aria-label="…"` (bilingual text passed in).
      - Output ≤ 8 KB for ~50 points: round coordinates to 1 dp, no whitespace padding.
      - Colors come from CSS (`stroke: var(--accent)` / `var(--neutral-bar)`), **not** hardcoded in SVG.
- [ ] `scripts/lib/chart.test.js`: scale math (0 maps to bottom, max maps to top padding), path starts
      with `M`, exactly N points produce N−1 `L` segments, output under 8 KB on a 50-point synthetic

## 5. Things a cheaper model gets wrong here — read twice

1. **Never hand-edit `public/index.html`, `public/en/index.html`, `public/state.json`** — edit templates
   and rebuild.
2. Every `{{TOKEN}}` used in a template must exist in `baseTokens()` or the build throws.
   The EN template needs its own wording tokens (`_EN`) — don't render Indonesian text into `/en/`.
3. Indonesian number formatting: thousands `.`, decimals `,` (`fmtId`, `fmtId1dp`). English: the reverse.
4. USD millions are ordinary numbers — **do not** wrap them in BigInt; the BigInt rule is for rupiah
   figures above ~9×10^15 only.
5. No new colours, fonts, icons, or libraries. If a styling need isn't in
   `design_handoff_utangindonesia/README.md`, use the closest existing token and note the deviation in
   the commit body.
6. No personal names/emails/paths anywhere (anonymity rule). Do not change the git identity.
7. Don't "fix" `STALE_DAYS_THRESHOLD`, sanity thresholds, or anything outside this plan's scope.
8. If SULNI numbers can't be read reliably — stop after T1's file skeleton and ask; a wrong number
   shipping live is worse than a late feature.
